# Автообновление прайса КУБКРАФТЕР

Раз в сутки скрипт собирает розничные цены с сайтов поставщиков
(planetadsp.ru и tbm.ru, город Краснодар) и записывает их в Google Таблицу
вместе с рассчитанной «нашей» ценой (по коэффициентам/дельтам из листа
«Настройки»).

## Структура таблицы (создаётся автоматически при первом запуске)

- **Настройки** — коэффициенты и дельты по поставщикам/линейкам. Правьте
  прямо в таблице, скрипт их не перезаписывает (только один раз заполняет
  при первом создании листа, если он пустой).
- **Прайс_Планета_Сервис** — текущие розничные цены и расчёт нашей цены.
- **Прайс_ТБМ** — то же самое для ТБМ.

Оба листа с прайсом при каждом запуске перезаписываются целиком (кроме
заголовка) — так корректно отражаются как новые позиции, так и те, что
пропали с сайта.

## Как это запускается

`.github/workflows/daily-update.yml` — раз в сутки (03:00 по Краснодару) и
вручную кнопкой **Run workflow** во вкладке **Actions** репозитория.

## Что нужно донастроить

1. Убедитесь, что в **Settings → Secrets and variables → Actions** лежит
   секрет `GOOGLE_SERVICE_ACCOUNT_KEY` (это вы уже сделали).
2. При желании добавьте туда же секрет `SPREADSHEET_ID` со значением ID
   вашей таблицы — либо оставьте как есть, ID уже прописан по умолчанию в
   `config.py`.
3. Загрузите все файлы из этой папки в корень репозитория
   `sidorovdmtr/Sec` (сохраняя структуру папок, включая `.github/workflows/`).
4. Зайдите во вкладку **Actions** репозитория, найдите workflow
   «Обновление прайса раз в сутки» и запустите его вручную кнопкой
   **Run workflow** — это первый тестовый прогон.
5. Откройте лог прогона (**Actions → выбрать прогон → update-price**) и
   пришлите мне, что там написано (особенно строки про количество найденных
   позиций и любые ОШИБКИ) — это единственный способ проверить, что
   разбор страниц реально работает, так как я писал код без доступа в
   интернет.

## Известные места, которые почти наверняка потребуют правки после первого прогона

- **Город на tbm.ru.** Как именно сайт переключается на Краснодар — не
  проверено вживую. Если в логе будет 0 позиций по ТБМ или цены явно
  московские — откройте сайт в браузере, переключите город на Краснодар,
  откройте вкладку **Network** в инструментах разработчика, обновите
  страницу и найдите запрос, отвечающий за город (имя cookie или параметр
  запроса) — пришлите мне, поправлю `scraper_tbm.py` за одну правку.
- **Категории на planetadsp.ru.** Список категорий в `CATEGORY_URLS` внутри
  `scraper_planeta.py` — не исчерпывающий (кромка, мойки и т.д. пока не
  включены). Дополняется одной строкой на категорию.
- **Дельта/коэффициент по линейкам Планета Сервис.** Пока ЭГГЕР,
  УЛЬТРАДЕКОР и ЛАМАРТИ используют ту же дельту −300 ₽, что подтверждена
  только для EVOGLOSS/ACM. Поправьте значения в листе «Настройки», когда
  будут точные данные по этим линейкам.

## Локальный запуск (для проверки на своём компьютере)

```bash
pip install -r requirements.txt
# положите скачанный JSON-ключ служебного аккаунта рядом со скриптом
# под именем service_account.json
python main.py
```
