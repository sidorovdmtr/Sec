# Инструкция для Claude Code

Проект: Kubcrafter, модуль «Деньги». Владелец Дмитрий. Сначала прочитай `HANDOFF.md` и `README.md`. Отвечай по-русски. По имени называй только Дмитрия.

## Правила

- Один вопрос за раз, вопросы нумерованным списком. Не придумывай факты: если данных нет, пиши «не определено» и спрашивай.
- Не меняй решения из Журнала решений без согласия Дмитрия: при противоречии покажи и спроси.
- Персональные данные (банковские выписки, сводная таблица денег, копии из инструмента) никогда не коммить, не копируй в чужие места и не вставляй в документы. Читай только нужный файл и только с разрешения Дмитрия. `.gitignore` уже закрывает xlsx, csv и файлы копий.
- Всё, что ты не смог проверить сам (iPhone, живой Firebase), скажи прямо и дай Дмитрию список проверок.

## Задача выкладки

1. Из `src` запусти `node test_core.js` и сборку `python3 build.py`, убедись, что корневой `index.html` свежий. Установи playwright и прогони `test_ui.js` и `test_sync.js`.
2. Создай репозиторий на GitHub, залей содержимое папки в корень, включи Pages (ветка `main`, корень). Дай Дмитрию адрес.
3. Помоги создать отдельный проект Firebase только для денег (Authentication Google, домен `<логин>.github.io` в разрешённых, база Firestore, веб-приложение). Регион базы выбирает Дмитрий, потом его не изменить: спроси.
4. Вставь конфигурацию в `config.js`, замени адрес Дмитрия в `firestore.rules` (спроси адрес) и идентификатор проекта в `.firebaserc`, выложи правила: `firebase deploy --only firestore:rules`.
5. Проверь живое подключение: вход Google, запись и чтение документов в `money_test_records` и `money_test_meta`. Если что-то не работает, найди причину в `src/app.js` (блок «синхронизация с Firebase») и исправь вместе с тестами.
6. Дай Дмитрию чек-лист проверки на iPhone: значок «Домой», офлайн, кнопка «Далее» в форме, обе темы, шрифт.

Рабочую базу (`allowProd: true`) не включай, пока Дмитрий не подтвердит проверку на тестовой.
